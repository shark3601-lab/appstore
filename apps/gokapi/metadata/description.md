# Gokapi

Condivisione file in stile WeTransfer, ospitata sul tuo server.

- Link che scadono dopo un numero di download o di giorni
- Password sul singolo file
- Crittografia, anche end-to-end
- Tema PZ: video di sfondo, vetro, logo a torcia

Al primo avvio si apre la configurazione iniziale. Il tema si attiva copiando i file in `app-data/.../gokapi/data/custom` e riavviando l'app.
